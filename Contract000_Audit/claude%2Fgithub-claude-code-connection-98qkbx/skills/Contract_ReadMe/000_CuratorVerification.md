2. Reconcile every listed source file as READ_WITH_FINDINGS, READ_NO_FINDINGS, REUSED_PINNED_READING, UNREAD, PARTIAL or BLOCKED. Directory verification alone cannot set READ.
3. Verify each discovery points to its actual branch/commit/path and the category accumulator. Retain unresolved source differences and audit boundaries.
4. Update the list-only header at the beginning of Contract000_auditskills.md and corresponding maintenance copies with exact branch/folder/file names. Preserve source fingerprints/checkpoints in the registry; retain historical lists in Git. Do not copy source contents into the header.
5. Update category and repository checkpoints, including next file/member, timestamp, source pins and handoff. On changed files revisit affected coverage. Never delete original histories, branches or research alternatives.
