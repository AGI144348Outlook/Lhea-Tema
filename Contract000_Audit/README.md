## Category collections

- **protocols:** Ordered rules and handoff obligations governing interactions; preserve trigger, preconditions, steps, returns and exceptions.
- **skills:** Reusable agent task procedures; record when to apply, prerequisites, steps, required capabilities, outputs and recovery.
- **capabilities:** Operations the implementation can actually provide; record inputs, outputs, prerequisites, effects and implementation evidence separately from proposals.
- **architectures:** Components, boundaries, dependencies, locality, layers, state ownership and composition structures.
- **interfaces:** MCP tools/resources/prompts and API/event/schema/adapter connection contracts; distinguish designed interfaces from served endpoints.
- **permissions:** Discovery, invocation and data scopes; authority, approval, expiry, revocation and enforcement boundaries. Never store credentials.
- **verifications:** Claims and their evidence, preregistration threads, observed results, failures, limitations and replay conditions.
- **operators:** Human, agent and service roles, responsibilities, runtime requirements, ownership and permitted operations.
- **glossaries:** Architecturally specific keyterms with contextual definitions, aliases, source meanings and unresolved differences.
- **tools:** Callable implementations and utilities; source entry points, argument/result contracts, dependencies, effects and actual availability.
- **pipelines:** Staged input, transformation and output flows; intermediate artifacts, dependencies and stage acceptance conditions.
- **workflows:** Task coordination, branching, approvals, retries, scheduling and return/handoff behavior.
